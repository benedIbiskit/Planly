Добавлено минимальное FastAPI-приложение Planly для практики №1. `GET /` возвращает `{"message": "Hello World"}`, `GET /health` — `{"status": "healthy"}`. Название и версия API отображаются в автоматически создаваемой документации.

Версии FastAPI, Uvicorn и зависимостей зафиксированы в `requirements.txt`. Добавлены отчёт и чек-лист выполнения практики. Базовая документация, правила работы и лицензия находятся в отдельном коммите в `main`.

Проверено на Python 3.12.14 в виртуальном окружении:

- Установка зависимостей из `requirements.txt` и `pip check`.
- Запуск Uvicorn с `--reload`.
- HTTP 200 и точное содержимое JSON для `/` и `/health`.
- HTTP 200 и HTML Swagger UI для `/docs`.
- Схема `/openapi.json`: Planly 0.1.0, оба эндпоинта.
- `git diff --check`; виртуальное окружение и локальные служебные файлы исключены из Git.
