## Что осталось для сдачи

### 1. Предоставить подключению GitHub право записи

Проверенные операции `git push` и GitHub API `create tree` возвращают HTTP 403. Изменения сохранены локально; записи в удалённый репозиторий не произошло. Требуется подключение GitHub с разрешением записи содержимого (`Contents: Read and write`) для `benedIbiskit/Planly`.

После обновления доступа из корня проекта:

```bash
git push -u origin main
git push -u origin feature/initial-setup
gh pr create --repo benedIbiskit/Planly --base main --head feature/initial-setup --title "feat: add initial FastAPI application" --body-file docs/pull-request-practice-1.md --reviewer benedIbiskit
```

Команды предполагают настроенную аутентификацию Git и GitHub CLI с правом записи. Если PR создаёт сам `benedIbiskit`, ревьюером должен быть другой участник команды.

### 2. Добавить преподавателя

Владелец открывает [Settings → Collaborators](https://github.com/benedIbiskit/Planly/settings/access), добавляет `andrey-limasov` с правом **Write** и отправляет приглашение. Преподаватель принимает приглашение. Текущее подключение не имеет административного доступа к репозиторию.

### 3. Провести ревью и слияние

Другой участник проверяет код и результаты запуска, оставляет `Approve`. После одобрения автор сливает PR в `main`. Затем команда отмечает оставшиеся пункты чек-листа и передаёт преподавателю ссылку на репозиторий и PR.
